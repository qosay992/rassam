# رسّــام ✨

**استوديو عربي لتوليد الصور بالذكاء الاصطناعي** — اكتب وصفك بالعربية واحصل على صورة احترافية.

نسخة عربية-أولاً بمفهوم Nover Studio: واجهة RTL كاملة، أنماط جاهزة، أفكار شامية مصنّفة، ومعرض محلي لأعمالك.

---

## المزايا

- 🖋️ **الكتابة بالعربية**: وصفك العربي يُحسَّن تلقائياً (ترجمة llama-3.3-70b ذكية + إثراء بصري) قبل إرساله للنموذج
- 🪄 **تحرير الصور (جديد)**: ارفع أي صورة أو استخدم صورة مولدة، واكتب أمر التعديل بالعربية — عبر FLUX.2 [klein] الذي يوحد التوليد والتحرير — مع معاينة قبل/بعد وتحرير متسلسل (حرّر نتيجتك مرة بعد مرة)
- 🎨 **10 أنماط**: واقعي، سينمائي، هوية عربية، إعلاني، أنمي… وغيرها
- 📐 **5 مقاسات** (مربع، أفقي، عمودي…)
- 💡 **أفكار جاهزة مصنّفة** + أوامر تحرير جاهزة
- 🗂️ **معرض محلي** (IndexedDB) — صورك لا تفقد وتبقى في متصفحك
- 🛡️ **فحص أمان مزدوج** (المدخل والبرومبت النهائي) + حد يومي + مانع إغراق
- 📱 **PWA** — قابل للتثبيت على الهاتف كتطبيق
- ⚡ **صفر تكلفة**: يعمل مجاناً عبر Pollinations، ويرتقي تلقائياً لـ Cloudflare FLUX عند إضافة المفاتيح
- 🔄 **سلسلة تنازل ذكية**: عند نفاد حصة Cloudflare أو ازدحامه ينتقل التوليد تلقائياً للمزوّد المجاني — لا يتوقف أبداً

## التشغيل المحلي

```bash
cd rassam
npm install
npm run dev
```

افتح http://localhost:3000 — يعمل فوراً بالوضع المجاني بدون أي مفاتيح.

> **ملاحظة**: أول تشغيل قد يُظهر صفحة بيضاء إن كان متصفحك فيه Service Worker قديم من مشروع آخر على نفس المنفذ — الموقع يتضمن `public/sw.js` يلغي تسجيله تلقائياً؛ حدّث الصفحة بـ Ctrl+Shift+R.

---

## الترقية للوضع السحابي (موثوقية أعلى + FLUX)

1. أنشئ حساباً على [Cloudflare](https://dash.cloudflare.com) (مجاني)
2. من لوحة التحكم: **Workers AI** → أنشئ **API Token** بصلاحية Workers AI
3. انسخ `.env.example` إلى `.env` واملأ:

```
CF_ACCOUNT_ID=معرف_حسابك
CF_API_TOKEN=رمز_الوصول
```

4. أعد تشغيل الخادم — كل الطلبات تذهب الآن إلى **FLUX.1-schnell** على Cloudflare (10,000 neurons يومياً مجاناً ≈ 150 صورة/يوم)، وحد المستخدم يبقى كما هو لحمايتك.

---

## النشر على الإنترنت (مجاني)

1. ارفع المشروع إلى مستودع GitHub
2. اربطه بـ [Vercel](https://vercel.com) (خطة Hobby مجانية)
3. أض متغيرات البيئة `CF_ACCOUNT_ID` و`CF_API_TOKEN` من إعدادات المشروع (اختياري — بدونهما يعمل بالوضع التجريبي)
4. نشر تلقائي مع كل دفعة (push)

> ⚠️ خدمات النشر والدفع قد تمنع التسجيل من بعض الدول — جرّب التسجيل أولاً قبل الاعتماد عليها، أو استضف لدى مزوّد يقبل منطقتك.

```
│   ├── quota.ts              # الحد اليومي + مانع الإغراق

    ├── icon.svg              # الأيقونة
    └── sw.js                  # ملغي تسجيل العمال القدامى
```

## القرارات الهندسية

- **Serverless inference فقط**: لا GPUs مملوكة — تدفع/تستهلك لكل صورة. الانتقال من المجاني للمدفوع = متغيرات بيئة فقط.
- **الحصة محفوظة في الذاكرة**: كافية لطبقة تجريبية بعقدة واحدة؛ عند النشر المتقدم تُستبدل بجدول (Upstash/Supabase) دون تغيير الواجهة.
- **فشل التوليد لا يستهلك الحصة**: العدّ يحدث بعد النجاح فقط.
